# v3.1.80 — In-app user guide and compact launch controls

## Основа

Версия собрана от принятого baseline `v3.1.79_launch_transparent_icon_set`, который был продолжением принятого `v3.1.75`.

## Что изменено

- На главный экран добавлена встроенная инструкция пользователя как часть интерфейса программы.
- Кнопка `Инструкция` размещена в правом launch-блоке рядом с переключателем темы, под ним.
- Переключатель темы в правой колонке уменьшен по высоте примерно вдвое, чтобы вместе с инструкцией занимать ту же вертикаль launch-кнопок.
- Инструкция открывается в модальном окне поверх текущего конструктора и закрывается по кнопке, клику на фон или клавише Escape.
- Документация внутри программы покрывает:
  - назначение приложения;
  - главный экран;
  - быстрый конструктор сцены;
  - быстрый конструктор ферм;
  - быстрый конструктор LED экранов;
  - PDF, техлисты и складские листы;
  - тему, mobile/desktop contract и общий порядок работы;
  - важные ограничения standalone-режима.

## UI-дисциплина

- Правка сделана через общие классы и глобальные стили:
  - `feg-launch-support-stack`;
  - `feg-launch-guide-button`;
  - `feg-user-guide-*`.
- Inline-style не добавлялись.
- CSS-иконки не возвращались.
- Responsive contract сохранён:
  - `<=767px` mobile;
  - `>=768px` desktop/tablet.
- Старые промежуточные breakpoint-переходы не возвращались.
- Wheel-bridge/manual scroll logic не возвращалась.

## Что не менялось

- Расчёты.
- BOM.
- Склад.
- Резервы.
- PDF export logic.
- Legacy/v3.
- Backend writes.
- Бизнес-логика конструкторов.
- Логика LED.
- Dark fallback.

## Проверки

Перед упаковкой должны пройти обязательные проверки `node --check`, CSS sanity / brace check и `unzip -t`.
