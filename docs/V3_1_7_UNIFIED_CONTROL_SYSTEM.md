# v3.1.7 — Unified control system

Цель: убрать разрозненные визуальные правки отдельных экранов и перевести Stage / Truss / LED на общий компактный стиль элементов управления.

Сделано:
- добавлен общий CSS-слой `styles/controls.css`;
- поля, select, input, checkbox, кнопки, панели и scale/zoom-блоки получили единый compact pro style;
- мобильный вид формы сцены переведён к компактному виду: подпись слева / поле справа для строковых контролов, три компактные колонки для размеров;
- scale/zoom-блок сцены поднят ближе к основным параметрам, чтобы не проваливался ниже пресетов;
- добавлены общие классы `feg-control-grid`, `feg-control-grid--rows`, `feg-control-grid--2`, `feg-control-grid--3`, которые можно использовать во всех конструкторах вместо локальных костылей;
- версия обновлена до 3.1.7.

Не менялось:
- расчёты;
- BOM;
- PDF-логика;
- localStorage drafts;
- quick catalog;
- склад / backend / сметчик.
