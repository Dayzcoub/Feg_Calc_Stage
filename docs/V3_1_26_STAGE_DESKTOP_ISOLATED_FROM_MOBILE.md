# v3.1.26 — Stage desktop isolated from mobile baseline

База: v3.1.21, то есть последний принятый вариант до desktop-проходов по сцене.

Что сделано:
- desktop-компоновка сцены перенесена поверх v3.1.21 только через `@media (min-width: 1180px)`;
- мобильные правила `max-width` не переписывались и не переносились из v3.1.24/v3.1.25;
- дополнительные wrapper-блоки summary, нужные desktop layout, на ширинах ниже 1180 px нейтрализуются через `display: contents`, чтобы мобильный поток оставался как в v3.1.21;
- desktop получает workstation layout: слева управление, по центру поле конструктора, справа метрики, подробные таблицы ниже.

Правило для следующих проходов:
- все desktop-правки — только в `@media (min-width: 1180px)` или в отдельном desktop-only файле/слое;
- mobile/tablet нельзя менять в рамках desktop задач;
- если desktop требует новой DOM-обёртки, для mobile/tablet должна быть нейтрализация или режим `display: contents`.
