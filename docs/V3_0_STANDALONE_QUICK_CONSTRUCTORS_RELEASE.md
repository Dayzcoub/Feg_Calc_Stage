# FEG Stage PRO 3.0 — Release Notes

**FEG Stage PRO 3.0** — это standalone-версия быстрых конструкторов сцены, ферм и LED-экранов, вынесенная в отдельное приложение с сохранением исходного внешнего вида, логики и расчётов.

В релизе сохранены локальные расчёты, PDF-экспорт, технико-комплектовочные сводки и быстрый доступ к трём конструкторам.

## Основное назначение

Версия 3.0 предназначена для оперативной работы на площадках, в полевых условиях и для быстрого технического просчёта конструкций без запуска основной системы.

## Главные изменения

- отдельный standalone-запуск быстрых конструкторов;
- титульный экран с новой карточкой **FEG Stage PRO 3.0**;
- три основные кнопки: **Сцена / Фермы / LED Экраны**;
- мобильная адаптация для телефонов;
- zoom, auto-fit и центрирование для Сцены и LED;
- сохранён PDF-экспорт со схемой и сводной таблицей.

## Формулировка релиза

FEG Stage PRO 3.0 — standalone-версия быстрых конструкторов для Stage, Truss и LED с локальными расчётами, сохранением конфигураций, экспортом PDF и мобильной адаптацией для работы на площадке.


## Состав сборки

- `index.html` — standalone shell и титульный экран 3.0;
- `assets/feg-stage-pro-3.0-title.png` — релизная картинка;
- `manifest.json` — PWA manifest версии 3.0;
- `src/modules/*` — исходные quick-модули, сохранённые для расчётов и экспорта;
- `README.md`, `CHANGELOG.md`, `RELEASE_NOTES_3_0.md` — документация релиза.

## Hotfix: Truss stool default node

- В быстром конструкторе ферм шаблон «Табуретка» снова по умолчанию строит углы из `U012`.
- Автоматическая замена углов табуретки на `U022` по наличию отключена для standalone quick-режима, чтобы поле конструктора строилось как в исходной логике быстрых шаблонов.
