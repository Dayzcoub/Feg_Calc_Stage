# v3.1.18 — Truss mobile viewport/button correction

Цель версии — закрыть визуальный регресс после v3.1.17 в мобильном ферменном конструкторе.

## Исправлено

1. Панель редактирования ферм
   - `v4-truss-edit-tools` на мобильном больше не наследует трёхколоночную раскладку старого inline-слоя.
   - Иконки `Повернуть / Удалить / Очистить` остаются компактной строкой.
   - Режимы `Добавлять / Удалять` вынесены в отдельную полноценную горизонтальную строку.

2. Поле конструктора
   - Убран конфликт `width:max-content !important` для `.v4-truss-field`.
   - Поле снова использует размеры, которые задаёт `V4StructureVisualConfigurator` исходя из `state.cols`, `state.rows` и текущего zoom.
   - Центрирование viewport теперь учитывает внутренний offset поля, если поле меньше окна конструктора и центрируется отступами.

3. Архитектурное правило
   - Исправления внесены через общий responsive layer и shared viewport logic.
   - Точечные CSS-костыли под один конкретный блок не добавлялись.

## Не менялось

- Расчёты ферм.
- BOM / комплектация.
- Quick catalog.
- Складская логика.
- PDF-экспорт.
- LED и Stage формулы.
