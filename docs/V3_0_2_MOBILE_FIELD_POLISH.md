# FEG Stage PRO 3.0.2 — Mobile Field Polish

Точечный UI-only hotfix для standalone quick constructors.

## Цель
Сделать быстрые конструкторы удобными для работы с телефона на площадке без изменения расчётов и логики.

## Что исправлено
- мобильные окна Stage / Truss / LED принудительно ограничены шириной экрана;
- убраны причины горизонтального переполнения всей страницы;
- панели настроек собраны в компактную одну колонку;
- широкие таблицы и технические блоки скроллятся внутри себя, а не двигают весь интерфейс;
- поле построения сцены центрируется внутри своего окна;
- поле построения ферм центрируется внутри своего окна;
- LED оставлен в рабочей логике, но выровнен с общей мобильной компоновкой;
- добавлено автоматическое повторное центрирование после применения шаблонов, zoom/fit и изменения ориентации телефона;
- скрыты лишние длинные подсказки на мобильном экране, чтобы не загромождать рабочую область.

## Не изменялось
- расчёты Stage / Truss / LED;
- BOM;
- quick ideal catalog;
- PDF export;
- Safari dark theme lock;
- hotfix табуретки U012.
