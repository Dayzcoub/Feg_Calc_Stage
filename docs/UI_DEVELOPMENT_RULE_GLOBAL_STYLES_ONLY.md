# UI development rule — global styles only

Для дальнейшей разработки и исправлений UI:

- не делать локальные CSS/JS-костыли под один конкретный блок, если задача относится к общему визуальному языку;
- все изменения шрифтов, полей, кнопок, отступов, панелей, сеток и состояний вести через глобальные токены и shared CSS-слои;
- Stage / Truss / LED должны использовать один общий визуальный язык;
- если нужен особый layout конкретного конструктора, он должен быть оформлен как системный компонент/группа классов, а не как inline-стиль или разовый runtime-patch;
- runtime JS не должен поверх глобальных CSS ломать визуальные правила без необходимости.

Цель: сохранить hard UI rebuild и не превратить проект обратно в набор разрозненных патчей.
