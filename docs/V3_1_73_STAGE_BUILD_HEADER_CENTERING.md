# v3.1.73 — Stage build header centering

## Что изменено

- Из блока быстрого построения сцены убрано отдельное поле с текстом `Клик / протяжка`.
- Заголовок `БЫСТРОЕ ПОСТРОЕНИЕ СЦЕНЫ` центрирован по освободившейся верхней полосе блока.
- Правка ограничена UI-слоем и не меняет поведение построения сцены.

## Что не менялось

- Расчёты, BOM, склад, резервы, PDF export, legacy/v3, backend writes.
- Responsive contract, native scroll, темы и логика конструкторов.
