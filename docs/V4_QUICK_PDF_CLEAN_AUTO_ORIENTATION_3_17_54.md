# v3.17.54 — Quick PDF clean rows and auto orientation

## Задача
Упростить quick PDF Stage/Truss/LED: убрать из видимых таблиц технические вторые строки с кодами вроде `TRUSS-QPRICE-RENTAL` и добавить автоматический выбор ориентации страницы для длинных таблиц.

## Что изменено
- В `QuickPdfExport` коммерческий блок больше не показывает код строки под названием позиции.
- Коммерческая таблица PDF теперь показывает только: позиция, количество, цена, сумма.
- В таблице комплектации PDF также скрыта вторая техническая строка с `code/id`; если названия нет, код всё ещё используется как fallback-название.
- Для quick PDF добавлен авто-выбор ориентации:
  - компактные таблицы остаются в альбомной ориентации;
  - длинные таблицы переключаются в книжную ориентацию;
  - в книжной ориентации схема и таблица идут вертикально, чтобы таблица не сжималась в узкую колонку.
- `PdfGenerator.createPdfBlob` получил безопасную поддержку `orientation`, `pdfOrientation`, `pageOrientation` и ширины контейнера. По умолчанию старое поведение остаётся альбомным.

## Границы правки
- Расчёты Stage/Truss/LED не менялись.
- `quickPricing` и технические коды сохраняются в данных, скрывается только их отображение в PDF.
- BOM, склад, резервы, quote mode, backend writes и legacy/v3 не менялись.
