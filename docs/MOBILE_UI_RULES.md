# Mobile UI Rules — v3.1.0

## Общие правила

- На ширине до 768px все основные блоки строятся в одну колонку.
- Горизонтальный scroll страницы запрещён: `html`, `body`, `v4-shell`, modal body и constructor roots ограничены `100vw`.
- Горизонтальный scroll разрешён только внутри таблиц и canvas/grid frames.
- Кнопки не переносят текст по буквам и имеют минимальную высоту 34px.
- Close button в modal frame — 44px.
- Основные labels — 10-11px uppercase, body text — 13-14px.

## Stage

1. Тип настила и тип столбов — в одной строке.
2. Перекладина — отдельная строка на всю ширину.
3. Ширина, глубина, высота — три колонки.
4. Закрытие торцов: select скрыт, пока checkbox выключен.
5. Стоимость, монтаж, доставка — три колонки.
6. Scale panel — компактные две строки.
7. Canvas не расширяет body.
8. Toolbar: Блок построения / Настил / Лестница / Очистить.
9. Технические bridge/debug блоки скрыты на mobile.

## Truss

1. Шаблоны идут сверху.
2. Pricing row под шаблонами.
3. Library и canvas не стоят рядом.
4. Zoom / fit / center доступны пальцем.
5. Stool template должен использовать U012.

## LED

1. Параметры кабинета читаемы.
2. Рабочее поле остаётся видимым.
3. Touch drawing сохраняется.
4. Таблицы и отчёты скроллятся внутри своих обёрток.
