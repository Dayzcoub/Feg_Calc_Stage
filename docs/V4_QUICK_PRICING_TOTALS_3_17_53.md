# v3.17.53 — Quick pricing totals for Truss / Stage / LED

Добавлен недостающий монтаж в быстрый конструктор ферм и закреплено правило итоговой стоимости для quick-калькуляторов.

## Quick Truss

- Добавлено поле `Монтаж, ₽`.
- Значение по умолчанию: `3500 ₽`.
- Поле `Доставка, ₽` сохранено со значением по умолчанию `4000 ₽`.
- Итог quick Truss теперь считается как:

```text
итого стоимость = прокат ферм + монтаж + доставка
```

В `section.quickPricing.rows` теперь попадают строки:

- `TRUSS-QPRICE-RENTAL` — расчётный прокат из быстрого конструктора;
- `TRUSS-QPRICE-INSTALL` — ручная стоимость монтажа;
- `TRUSS-QPRICE-DELIVERY` — ручная стоимость доставки.

## Quick Stage

Проверено правило расчёта:

```text
итого стоимость = количество модулей × цена за модуль + монтаж + доставка
```

Дефолты сохранены:

- модуль сцены: `850 ₽`;
- монтаж: `3500 ₽`;
- доставка: `4000 ₽`.

## Quick LED

Проверено правило расчёта:

```text
итого стоимость = количество LED-кабинетов × цена за кабинет + монтаж + доставка
```

Дефолты сохранены:

- LED кабинет/модуль: `800 ₽`;
- монтаж: `1500 ₽`;
- доставка: `2000 ₽`.

## Видимость и границы

- Все commercial rows остаются в `section.quickPricing`, `section.pricing.quick`, `section.commercialRows`, `section.commercialTotals`.
- Блок скрывается для ролей без `quick_pricing:view` / `prices:view` и для пользователей с `prices:hidden`.
- Эти строки не попадают в складской BOM, warehouse rows, резервы и backend writes.
- Quote-mode, shared BOM, LoadChecker и legacy/v3 не менялись.
