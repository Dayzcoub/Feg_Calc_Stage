# v3.1.15 — Stage mobile compact dimensions/closure rhythm

Цель: убрать лишнее расстояние между блоком размеров сцены (`Ширина / Глубина / Высота`) и строкой закрытия торцов (`Включить закрытие торцов` + `Тип`).

Изменения:
- добавлен глобальный responsive override в `styles/breakpoints.css`;
- для ширин до desktop (`<=1179px`) зазор в `v4-stage-controls-layout` стабилизирован через `row-gap`;
- у dimensions/closure блоков обнулены дополнительные нижние/верхние отступы;
- на очень узких экранах (`<=390px`) сохранён ещё более компактный ритм.

Не менялось:
- структура данных;
- расчёты сцены;
- BOM/PDF;
- логика построения и шаблоны.
