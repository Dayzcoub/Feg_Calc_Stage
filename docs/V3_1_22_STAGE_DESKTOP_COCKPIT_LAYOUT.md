# v3.1.22 — Stage desktop cockpit layout pass

Что исправлено в десктопной версии быстрого конструктора сцены:
- верхняя панель сцены больше не растягивает все поля в одну длинную строку;
- блоки `тип настила / столбы / перекладина`, `габариты`, `закрытие торцов`, `стоимость` получили отдельные компактные desktop-карточки;
- блок масштаба переведён в читаемый desktop-ритм вместо длинной полосы на всю ширину;
- блок построения, пресеты и подсказка получили ровную горизонтальную компоновку;
- окно конструктора уменьшено до рабочей высоты desktop-viewport и центрирует сетку по горизонтали;
- карточки итогов и таблицы сцены сделаны крупнее и читабельнее на десктопе.

Технический принцип:
- правка внесена глобально в `styles/breakpoints.css` как desktop responsive layer;
- расчёты Stage, BOM, PDF, quick pricing и складские/резервные механики не менялись;
- локальные CSS-костыли под конкретный скрин не добавлялись.
