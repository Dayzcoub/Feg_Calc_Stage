# v3.1.10 — Stage mobile structural flow

Цель: привести мобильную панель Stage к фактической сетке, которую можно использовать, а не к набору CSS-костылей поверх старого layout.

Сделано:
- Stage-поля получили явные shared-классы: deck/support/dimensions/pricing/presets.
- Mobile Stage layout задан в `styles/controls.css` как общий control-flow слой.
- Верхняя группа: настил + столбы в один ряд, перекладина на всю ширину.
- Размеры: ширина/глубина/высота в один ряд после тонкого divider.
- Закрытие торцов: checkbox + select, без лишнего заголовка типа.
- Стоимость: общий центрированный заголовок и три поля в один ряд.
- Масштаб: `− / slider / +`, ниже `По размеру / Центр / auto-fit`.
- Блок построения без заголовка, три кнопки в одну строку.
- Пресеты: две колонки, нормальные inline-иконки.
- Canvas после настроек ограничен по высоте, но остаётся скроллируемым.

Не менялось:
- расчёты;
- BOM;
- PDF;
- quick catalog;
- localStorage drafts;
- backend / склад / сметчик.
