# FEG Stage PRO v3.17.46 — Quick calculators PDF export

## Назначение
Добавлен единый PDF-экспорт для быстрых технических конструкторов:

- быстрый конструктор сцены;
- быстрый конструктор ферм;
- быстрый конструктор LED-экранов.

PDF нужен для быстрого техлиста без клиента, цен, КП, склада, резервов и дефицита.

## Что изменено

### 1. Новый модуль
Добавлен модуль:

```text
src/modules/QuickPdfExport.js
```

Он отвечает за:

- сбор HTML-макета PDF;
- добавление сводной таблицы комплектации;
- вставку визуализации текущего конфига через `VisualExport`;
- создание PDF через существующий `PdfGenerator`;
- предпросмотр в iframe;
- скачивание PDF;
- отправку через системный `navigator.share`, где браузер поддерживает отправку файлов.

### 2. Кнопки в quick-конструкторах
Кнопка PDF добавлена под итоговой/сводной таблицей quick-режима:

- Stage quick summary;
- Truss quick final kit table;
- LED quick result table.

Для quote/сметного режима кнопка не добавляется этим релизом.

### 3. Что входит в PDF

PDF содержит:

- заголовок быстрого расчёта;
- дату генерации;
- сводные карточки;
- визуализацию текущего конфига;
- таблицу комплектации/BOM;
- технический footer с версией экспортёра.

### 4. Отправка в мессенджер
Кнопка «Отправить» использует Web Share API:

- на мобильных устройствах открывает системное меню отправки, включая доступные мессенджеры;
- если браузер не поддерживает отправку PDF-файла, PDF скачивается и показывается подсказка отправить файл вручную.

## Границы изменений

Не менялись:

- расчёты Stage/Truss/LED;
- shared BOM формулы;
- сметчик/Quote Wizard;
- склад;
- дефицит;
- совместимые замены ферм;
- субаренда;
- backend-записи;
- legacy/v3.

## Smoke-проверки

- `QuickPdfExport.buildSmokeReport()` возвращает стабильный отчёт.
- В `index.html` подключён `src/modules/QuickPdfExport.js` после visual export stack.
- Service worker кеширует новый модуль.
- Stage/Truss/LED quick UI получают кнопку через общий `renderActionHtml()` и `bindAction()`.
