# v3.1.13 — Pre-desktop responsive usability

Цель: привести все промежуточные расширения окна до desktop к логике мобильной версии, не трогая финальный desktop layout.

Изменено:
- для ширины до 1179px Stage использует мобильную логику сетки, без гибридного desktop/tablet состояния;
- блок масштаба исправлен: минус слева, плюс справа, slider между ними, ниже читаемая строка По размеру / Центр / auto-fit;
- убраны промежуточные вылеты draw-help и scale label в узких состояниях;
- инструментальные кнопки и пресеты стабилизированы в читаемые строки/две колонки;
- desktop >=1180px намеренно не менялся.

Не менялось:
- расчёты;
- логика построения;
- BOM/PDF;
- quick catalog и drafts.
