# FEG Stage PRO 3.0 — Mobile dark UI parity

Точечная правка мобильной standalone-версии быстрых конструкторов.

## Цель

Свести мобильный интерфейс к той же тёмной desktop/V4-палитре, чтобы на телефоне не появлялись светлые панели, слабоконтрастный текст или разноцветные служебные стили.

## Что изменено

- добавлен модуль `src/modules/MobileDarkUiParity.js`;
- модуль подключён после `V4DesignSystem.js`, поэтому его стили применяются последними;
- мобильные quick-модалки Stage / Truss / LED получили единую тёмную палитру;
- тёмные цвета закреплены для карточек, полей, кнопок, таблиц, canvas-зон, BOM, PDF-модалки и zoom-панелей;
- текстовые элементы принудительно приведены к контрастным цветам: основной текст светлый, вторичный текст серый, акцент — жёлто-золотой.

## Не менялось

- расчёты Stage / Truss / LED;
- BOM;
- PDF-экспорт;
- quick pricing;
- локальное сохранение;
- zoom / auto-fit;
- структура данных и логика конструкторов.

### Hotfix 3.0 mobile dark UI
- Исправлен зависон на титульном экране: мобильный dark-ui слой больше не конфликтует с `V4DesignSystem` через `MutationObserver` в `<head>`.
- Кнопки выбора конструкторов снова загружаются сразу после титульной картинки.
