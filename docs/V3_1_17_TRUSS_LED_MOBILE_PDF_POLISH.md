# v3.1.17 — Truss / LED mobile polish and Quick PDF scheme fix

## Цель
Точечный проход после v3.1.16 без возврата к локальным CSS-костылям: правки в общих responsive-паттернах, компонентных классах и Quick PDF exporter.

## Что изменено
- Truss / блок «Табуретка»: поле «Кол-во ног» и кнопка «Добавить табуретку» переведены в одну горизонтальную строку.
- Truss / инструменты редактирования: режимы «Добавлять» и «Удалять» закреплены как единая горизонтальная строка рядом с общим ритмом кнопок редактирования.
- Truss / поле конструктора: добавлено центрирование построенных шаблонов внутри сетки и центрирование viewport по фактическому содержимому при auto-fit.
- LED / active construction: селект активной конструкции приведён к общему размеру текста выпадающих списков в compact mobile layout.
- LED / результат: из публичного вывода убраны кнопки «Показать техлист», «Складской лист LED», «LED BOM bridge»; оставлена только единая PDF-кнопка.
- Quick PDF: для Truss добавлен SVG fallback схемы на основе текущих `section.input.items`, поэтому PDF больше не зависит только от html2canvas-снимка поля.
- Quick PDF: верхний hero-блок переведён на читаемую светлую палитру в тон остальным карточкам PDF.

## Границы
- Расчёты Stage / Truss / LED не менялись.
- BOM, склад, quote mode, drafts, quick catalog и pricing formulas не менялись.
- Внутренние LED sheet/BOM renderers оставлены в коде для диагностики quote/bridge, но больше не показываются кнопками в quick UI.
