# FEG Stage PRO 3.0.7 — Stage mobile UI hotfix

Точечный мобильный hotfix для конструктора сцены.

## Исправлено
- Восстановлено рисование пальцем/мышкой по полю сцены.
- Исправлена компоновка панели масштаба на мобильных устройствах.
- Кнопки «По размеру», «Центр» и чекбокс «Авто» уложены в одну компактную горизонтальную строку.
- Скрыты технические блоки «Связь столб/перекладина» и «Stage BOM bridge» в мобильном режиме.

## Не менялось
- Desktop layout.
- Расчёты Stage / Truss / LED.
- BOM.
- PDF export.
- Quick ideal catalog.
