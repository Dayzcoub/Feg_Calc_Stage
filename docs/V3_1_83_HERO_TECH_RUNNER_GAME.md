# v3.1.83 — Hero artwork mini-runner game

Версия собрана от принятого baseline `v3.1.82_detailed_constructor_guide`.

## Что добавлено

- Добавлена скрытая мини-игра `FEG TECH RUN` в стиле offline runner.
- Запуск игры выполняется кликом / Enter / Space по широкой hero-картинке на главном экране standalone-приложения.
- Игровой персонаж — техник с кейсом.
- Препятствия соответствуют предметной области приложения:
  - ферма;
  - сцена;
  - LED-кабинет;
  - кабель;
  - элемент декора.
- Управление:
  - `Space`, `ArrowUp`, `W` / `Ц`;
  - клик по игровому полю;
  - тап на мобильном устройстве;
  - отдельная кнопка `Прыжок`.
- Очки и дистанция считаются во время забега.
- После столкновения результат сохраняется в общую локальную базу рекордов standalone-приложения.
- Перед стартом можно указать имя техника; имя сохраняется локально и подставляется в следующем запуске.
- Таблица рекордов показывает лучшие результаты.

## Граница изменений

- Мини-игра живёт отдельным модулем `src/modules/MiniRunnerGame.js`.
- Для хранения результатов используется `localStorage`:
  - `fegStagePro.runnerScores.v1`;
  - `fegStagePro.runnerPlayerName.v1`.
- Backend-записи, склад, резервы, quote_items, BOM и расчётные формулы не затрагивались.
- Игра не меняет состояние конструкторов и не влияет на PDF/техлисты.

## UI

- В hero-картинку добавлен ненавязчивый hover/focus бейдж `FEG TECH RUN`.
- Модалка игры поддерживает dark/light тему.
- Мобильный запуск доступен, но основная сетка приложения и responsive contract не менялись.
