# v3.1.11 — Stage mobile usability polish

Цель: довести мобильный блок сцены до нормальной читаемости и управляемости без локальных UI-костылей.

Сделано:
- компактные отображаемые option labels для Stage select: ключи и расчёты не меняются;
- уменьшены размеры подписей и значений в полях Stage mobile;
- верхние select больше не должны обрезать основной смысл значения;
- scale-блок приведён к двум строкам: `− / slider / +` и `По размеру / Центр / auto-fit`;
- подпись/проценты масштаба скрыты;
- tool row остаётся в одну строку;
- пресеты закреплены в двухколоночной сетке;
- canvas Stage увеличен и лучше помещается в мобильный экран.

Не менялось:
- расчёты Stage;
- BOM;
- PDF;
- localStorage drafts;
- quick catalog.
