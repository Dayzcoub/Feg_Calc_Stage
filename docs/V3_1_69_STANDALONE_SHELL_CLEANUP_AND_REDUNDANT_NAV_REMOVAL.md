# v3.1.69 — Standalone shell cleanup and redundant nav removal

## Что изменено

- Полностью убрана верхняя standalone-панель оболочки (цветные window-controls, брендовый title-strip и центральная подпись `Stage · Truss · LED`).
- Полностью убран дублирующий нижний ряд вкладок `Сцена / Фермы / LED Экраны` внутри workspace-карточки.
- Переключение конструкторов теперь идёт только через основной ряд больших launch-кнопок.
- Ранее перенесённый переключатель темы остаётся справа от больших кнопок и не затрагивается.

## Что не менялось

- Расчёты, BOM, склад, резервы, PDF export, legacy/v3, backend writes.
- Responsive contract `<=767 mobile / >=768 desktop`.
- Native browser scroll и dark fallback.

## Причина

Пользователь подтвердил, что оба выделенных красным служебных блока визуально лишние и должны быть удалены из shell полностью, без замены локальными hide-хакми в отдельных экранах.
