# v3.1.88 — FEG TECH RUN: настройка физики прыжка

## Что изменено

- Уменьшена высота прыжка техника: прыжок больше не уходит слишком высоко за пределы игровой сцены.
- Сокращено время удержания восходящего импульса прыжка.
- Добавлено более выраженное падение: техника быстрее возвращает на землю после верхней точки.
- Физика прыжка переведена на нормализованный шаг кадра, чтобы поведение меньше зависело от частоты обновления экрана.
- Препятствия и Supabase-рекорды не менялись.

## Новые параметры прыжка

Параметры находятся в `src/modules/MiniRunnerGame.js`:

```js
const RUNNER_PHYSICS = Object.freeze({
  groundY: 286,
  jumpVelocity: -14.4,
  jumpHoldMs: 45,
  ascentGravity: 0.68,
  fallGravity: 1.05,
  maxFallSpeed: 18.2
});
```

Логика:

- `jumpVelocity` задаёт стартовый рывок вверх;
- `jumpHoldMs` отвечает за короткую фазу подъёма;
- `ascentGravity` работает на подъёме;
- `fallGravity` сильнее подъёмной гравитации, поэтому прыжок ощущается менее «лунным»;
- `maxFallSpeed` ограничивает скорость падения.
