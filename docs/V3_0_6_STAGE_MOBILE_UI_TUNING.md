# FEG Stage PRO 3.0.6 — Stage mobile UI tuning

Scope: mobile-only visual tuning for the standalone quick Stage constructor.

Changed:
- Stage deck/support selectors are compacted into one horizontal row on mobile.
- Stage frame indicator stretches full width below deck/support selectors.
- Width/depth/height inputs are compacted into one horizontal row.
- Edge closure type selector is hidden until edge closure is enabled.
- Quick pricing inputs are compacted into one horizontal row: unit cost / install / delivery.
- Stage presets are compacted into smaller buttons.
- Stage zoom panel is compacted: fit / center / auto-fit share one horizontal row.
- Stage build tools moved visually below the constructor field on mobile.
- Clear button is moved into the build tools row on mobile.
- Stage summary cards are compacted into three columns.
- Mobile view hides stage technical notes for column/frame dependency and Stage BOM bridge.

Not changed:
- Desktop layout.
- Stage calculations.
- BOM and PDF export.
- Truss and LED constructor logic.
