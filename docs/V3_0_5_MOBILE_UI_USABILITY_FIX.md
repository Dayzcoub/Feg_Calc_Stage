# FEG Stage PRO 3.0.5 — Mobile UI usability fix

Цель hotfix: привести мобильное отображение standalone quick constructors в рабочее состояние без риска повторного зависания интерфейса.

## Что исправлено

- Stage / Truss / LED модалки принудительно ограничены шириной экрана телефона.
- Desktop-сетки теперь безопасно перебиваются более специфичными mobile-правилами.
- У ферм библиотека, инструменты, zoom и поле построения идут одной колонкой.
- У сцены контролы, zoom и поле построения идут одной колонкой.
- У LED сохранён рабочий вид, но он выровнен под общую мобильную оболочку.
- Широкие таблицы, BOM и отчёты скроллятся внутри себя, не растягивая весь экран.
- Добавлено безопасное центрирование рабочих областей по событиям click/resize/orientationchange.

## Важно

Нет `MutationObserver` и нет принудительной перестройки DOM. Изменения находятся в `StandaloneMobileFieldPolish.js`, но слой работает как CSS-first и не меняет расчёты.

## Не менялось

- Расчёты Stage / Truss / LED.
- BOM.
- PDF-экспорт.
- Quick ideal catalog.
- Safari dark theme lock.
- Табуретка U012.
