# v3.17.51 — Quick Stage/LED manual pricing

## Что добавлено

В быстрые конструкторы сцены и LED добавлен отдельный коммерческий слой ручной стоимости. Он не входит в складской BOM и не меняет расчёты комплектации.

### Быстрая сцена

Поля стоимости:

- стоимость за 1 модуль: 850 ₽ по умолчанию;
- монтаж: 3500 ₽ по умолчанию;
- доставка: 4000 ₽ по умолчанию.

Итог считается как:

```text
стоимость модулей = количество модулей × цена за модуль
итого = стоимость модулей + монтаж + доставка
```

### Быстрый LED

Поля стоимости:

- стоимость за 1 модуль / кабинет: 800 ₽ по умолчанию;
- монтаж: 1500 ₽ по умолчанию;
- доставка: 2000 ₽ по умолчанию.

Итог считается как:

```text
стоимость кабинетов = количество активных кабинетов × цена за кабинет
итого = стоимость кабинетов + монтаж + доставка
```

## Видимость и роли

Добавлен общий helper `QuickPricing.js`.

Коммерческий блок доступен пользователям с правами:

- `quick_pricing:view`;
- `prices:view`;
- полный доступ `admin/director/tech_director`.

Для ролей с `prices:hidden` блок не выводится в UI и не попадает в быстрый PDF. На данном этапе это UI/role guard слой; для production-скрытия цен окончательное решение должно быть продублировано backend/RLS-правами.

## Структура данных

Коммерческие строки сохраняются отдельно от BOM:

```text
section.quickPricing
section.pricing.quick
section.commercialRows
section.commercialTotals
```

Все строки помечены:

```text
commercial: true
sourceType: quick_manual_price
visibility.permission: quick_pricing:view
visibility.hideFromWarehouse: true
```

## Что не менялось

- shared-core расчёты сцены/LED;
- сметчик quote-mode;
- legacy/v3;
- складские резервы;
- backend writes.
