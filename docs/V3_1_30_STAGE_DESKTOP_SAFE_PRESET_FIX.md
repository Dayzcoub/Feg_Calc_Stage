# v3.1.30 — Stage desktop safe preset fix

База: v3.1.26.

Что сделано:
- отменены ошибочные desktop layout-слои v3.1.28/v3.1.29, которые ломали рабочую сетку сцены;
- оставлена только безопасная desktop-правка блока пресетов сцены;
- добавлен нормальный `gap` между иконкой и текстом/цифрами в кнопках пресетов;
- скрыта кнопка `Очистить` из нижнего блока пресетов;
- мобильный и tablet-слои не изменялись.

Правило:
- пользовательские правки по умолчанию относятся к desktop;
- правки должны попадать только в `@media (min-width: 1180px)`, если явно не указано mobile/tablet.
