# v3.1.23 — Stage desktop workstation layout pass

Что изменено:
- desktop-сцена больше не растягивает все контролы одной длинной верхней полосой;
- рабочая область перестроена в desktop workstation: слева управление, по центру поле конструктора, справа ключевые метрики;
- детальные BOM/ценовые таблицы вынесены в широкий нижний ряд;
- блок масштаба и пресеты живут внутри левой панели управления, а не занимают всю ширину экрана;
- поле конструктора центрирует сетку по вертикали и горизонтали внутри рабочей зоны;
- для средних desktop-экранов 1180–1500 px включается двухколоночный fallback: управление + поле, метрики и таблицы ниже.

Технический принцип:
- расчёты, BOM, PDF, pricing и склад не менялись;
- структура вывода summary разделена на `v4-stage-summary-metrics` и `v4-stage-summary-details`;
- основная компоновка сделана в глобальном responsive layer `styles/breakpoints.css`, без локальных inline-костылей.
