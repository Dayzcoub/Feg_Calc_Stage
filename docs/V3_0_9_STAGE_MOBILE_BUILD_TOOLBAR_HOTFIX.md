# FEG Stage PRO 3.0.9 — Stage mobile build toolbar hotfix

Scope: standalone quick constructors, mobile Stage UI only.

## Changes

- Reduced the visual weight and font size of the `Блок построения` label.
- Kept the construction toolbar horizontal on small screens.
- Reduced button gaps and button font size.
- Forced `Настил`, `Лестница`, and `Очистить` to remain single-line labels.

## Not changed

- Desktop UI.
- Stage calculation logic.
- Truss / LED constructors.
- BOM / contract snapshot logic.
- PDF export.
- Safari dark theme lock.
- Stage touch-drag drawing hotfix.
