# FEG Stage PRO 3.0.8 — Stage mobile touch-drag hotfix

Точечный hotfix только для мобильного отображения конструктора сцены.

## Что исправлено

- Рисование сцены пальцем на мобильных браузерах снова работает протяжкой по нескольким клеткам.
- Добавлен безопасный touch-drag proxy для мобильных браузеров: `touchmove` внутри поля сцены прокидывается в существующую pointer-логику конструктора.
- Не добавлены агрессивные `MutationObserver` и не выполняется перестройка DOM.
- Блок «Масштаб поля» переведён на устойчивую 12-колоночную сетку:
  - `− / шкала / +` — первая строка;
  - `По размеру / Центр / Авто` — вторая строка равными зонами.

## Что не менялось

- Desktop UI.
- Расчёты сцены.
- BOM / PDF.
- Quick ideal catalog.
- Фермы и LED.
