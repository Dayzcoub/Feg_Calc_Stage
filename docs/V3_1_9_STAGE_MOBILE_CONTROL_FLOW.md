# v3.1.9 — Stage mobile control flow

Исправления сделаны через shared CSS-слой `styles/controls.css` и минимальную семантическую разметку формы сцены.

Сцена / mobile:
- верхний блок `Тип настила / Тип столбов / Перекладина` оставлен по расположению;
- уменьшены подписи и значения внутри полей;
- добавлены тонкие разделители между группами параметров;
- `Ширина / Глубина / Высота` выстроены в горизонтальный ряд;
- блок закрытия торцов оставлен как checkbox + select, подпись select скрыта в mobile;
- `Стоимость быстрого расчёта` центрирована отдельным заголовком, поля цены идут в горизонтальный ряд;
- scale-блок: `−`, slider, `+` в одной строке; `По размеру / Центр / auto-fit` во второй строке;
- индикатор процентов масштаба скрыт;
- блок построения без подписи, кнопки идут в одну строку;
- пресеты сгруппированы в две колонки и получили компактные иконки;
- canvas сцены ограничен по высоте и работает с auto-fit для вписывания активной части.

Не менялось:
- расчёты;
- BOM;
- PDF;
- quick catalog;
- localStorage drafts;
- warehouse/backend.
