# v3.1.37 — Truss / LED desktop workstation parity

Что сделано:
- desktop-компоновка ферм и LED приведена к принципу финальной сцены v3.1.36;
- левая колонка стала рабочей панелью управления: шаблоны, параметры, цена, библиотека/active construction;
- центр отдан под поле конструктора с масштабом;
- правая колонка отдана под ключевые метрики;
- подробные таблицы, BOM, pricing и PDF-действия вынесены вниз на всю ширину;
- блоки масштаба Truss/LED используют тот же ритм, что финальная сцена: верхняя строка `− / slider / +`, нижняя строка `По размеру / Центр / auto-fit`;
- mobile/tablet не затрагивались: все layout-правки лежат только в `@media (min-width: 1180px)`.

Принцип:
- без точечных inline/CSS-костылей;
- все правки через shared desktop layout layer;
- Stage v3.1.36 считается эталонной компоновкой для quick-конструкторов.
